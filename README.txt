MAHU INTERIOR — LABOUR MANAGER V3
=================================
Android-first offline web app.

V3 visual improvements:
- Original MAHU INTERIOR logo cropped from the supplied ID-card photo, cleaned and enhanced.
- Copper, black and warm ivory brand palette.
- Dark mode contrast fixes: visible text, labels, fields, selects, pills, navigation, notices, tables and status colours.
- Light/dark theme toggle.

Existing app features retained:
- Worker profiles and individual daily wages
- Daily attendance
- Labour advances, running payments and salary payments
- Combined All Expenses history
- PDF/print and CSV export
- Local automatic backup and manual JSON backup/restore

ANDROID / GITHUB PAGES UPDATE:
1. Extract this ZIP.
2. In your GitHub repository, choose Add file > Upload files.
3. Upload all files from this folder to the repository root (same level as index.html).
4. Commit changes.
5. Wait for GitHub Pages deployment.
6. Close the old app tab and reopen the site. If needed, use an Incognito tab once to verify the latest version.

IMPORTANT DATA SAFETY:
- Keep the same GitHub Pages site/origin if you want to keep using its existing local records.
- Do not clear Chrome site data.
- Download a JSON backup before changing repository/site or clearing browser data.
- Local browser storage is device- and website-origin-specific; this app does not sync records to cloud.
